## Completeness Definitions

- **Complete**: the original main-session JSONL exists and a sanitized copy is retained in the repository; required sub-agent and tool-result artifacts are retained only for selected sessions.
- **Partial**: only part of the main session, sub-agent output, or tool results is retained. The initial manifest adds no new entries in this category.
- **Memory summary only**: only a memory summary remains; no claim is made that a complete session is available.
- **Index only**: only the session ID, project identifier, and historical index metadata are retained; no claim is made that a complete session is available.

> Raw session JSONL and captured tool output retain their original wording as provenance evidence.
