# rosbridge :9090 无认证订阅/发布/服务调用（含固件升级接口暴露）

> 版本：2026-08-29 · 方法：报告级证据（实机枚举已由研究完成）+ 在线情报确认
> **边界声明**：rosbridge 仅做只读验证（订阅/枚举），**未发布任何 topic**；运动控制/舵机/导航
> 类接口遵守红线一律不触碰。

---

## 1. 执行摘要

**vision 板 :9090 运行 rosbridge_suite（ROS2 WebSocket），无任何认证——ROS2 版 rosbridge 无
`rosauth` 等价物（在线情报确认），匿名即可订阅、发布、调用 service。已实测：匿名订阅
`/emb/battery_state` 成功；`advertise` 静默接受（发布通道开放）；空参调用 `/emb/getVer`、
`/sys/sn/read`、`/emb/bat_info_get` 返回板卡固件版本（BMS 1.0.32/2025-12-16 等）。
高危 topic 面含 EtherCAT 舵机原始访问 `/ecat/servo/access_sdo_16`、导航命令 `/vnav/task/command`、
`/sys/wifi/set_ap`、语音 `/sys/speech/tts`、摄像头 `/vnav/vslam/track_image`。
此外暴露固件升级 service `/emb/upgrade`（未调用）。**

严重度定级：**严重（Critical）**——未认证访问机器人内部 ROS 总线，触达运动/固件/网络配置。

---

## 2. 根因与在线情报

- **根因**：rosbridge_suite 默认不启用认证；ROS2 版本**无 rosauth 等价物**（ROS1 才有
  `rosauth --authenticate`），这是官方已知设计缺陷（非 CVE，架构性问题）。
- **实测**：匿名订阅成功、advertise 接受、service 可调（报告 2026-08-29 实机枚举，99 个 service 名录提取）。

## 3. 攻击面

| 类别 | 具体 | 风险 |
|---|---|---|
| 订阅 | 任意 topic（含 `/emb/battery_state` 已实测） | 传感器/状态数据被动窃取 |
| 发布 | advertise 接受 → 伪造 topic | 注入假状态（电池/传感器）干扰控制决策 |
| service | `/emb/getVer` `/sys/sn/read` `/emb/bat_info_get` 已调通 | 板卡版本/标识泄露 |
| 固件升级 | `/emb/upgrade`（**未调用**） | 潜在固件升级劫持/降级 |
| 高危 topic | `/ecat/servo/access_sdo_16`（EtherCAT 舵机原始访问）、`/vnav/task/command`、`/sys/wifi/set_ap`、`/sys/speech/tts`、`/vnav/vslam/track_image` | 运动控制/网络/摄像头（红线：不触碰） |

## 4. 受影响范围

- 组件：rosbridge_suite（ROS2，:9090 WS，无认证）
- 入口：`ws://192.168.11.3:9090`


## 6. 修复建议

1. rosbridge 增加认证（接入现有 JWT/会话体系；上游无内建时自建网关）；
2. 对高危 topic（EtherCAT/导航/WiFi）做订阅/发布 ACL；
3. `/emb/upgrade` 加认证与版本/签名校验；
4. 网络层限制 :9090 仅内网管理面可达。
