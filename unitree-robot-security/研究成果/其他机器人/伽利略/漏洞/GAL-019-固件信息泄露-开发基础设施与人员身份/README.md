## 2. 影响

- **供应链风险**：内网 GitLab 地址 + 仓库结构 + 版本矩阵，攻击者可精准定位目标代码/版本；
- **人员风险**：开发者实名 + 内部 ID，可构建钓鱼/社工画像；
- **残留后门风险**：前任 SSH 公钥可能仍在 authorized_keys，设备转手后前任仍可登录；
- **情报价值**：前任完整渗透轨迹（takeover 命令、LCM spy、fusepwn）直接复用。

## 3. 修复建议

1. 出厂/交付镜像清理 home 目录残留（.bash_history/.viminfo/Readme/123/ 打包残留）；
2. Readme 类构建产物不含内网地址与作者实名（脱敏）；
3. 交付前重置 authorized_keys；
4. 数据库凭据不入固件（每设备独立凭据 + 密钥管理）。
